# Murli Khaire – Portfolio

Personal portfolio of **Murli Khaire**, Backend Engineer at ConvoZen.ai (Java, Spring Boot, Kafka, AI/LLM pipelines).

🔗 **Live:** https://murli0399.github.io

## Sections

Home · About · Experience · Skills · Projects (work highlights, open-source interview prep repos, personal projects) · GitHub activity · Contact

## Tech

- Plain HTML, CSS and JavaScript: no build step, served by GitHub Pages
- Responsive layout with a mobile menu, scroll animations and a typing effect
- Contact form via [FormSubmit](https://formsubmit.co), so no passwords or API keys live in the code
- GitHub stats cards generated by the workflow in the [Murli0399/Murli0399](https://github.com/Murli0399/Murli0399) profile repo

## Run locally

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

## Updating content

- Text and links: `index.html`
- Styles and colours (CSS variables at the top): `styles/main.css`
- Typing phrases and contact form behaviour: `script/main.js`
- Resume: replace `img/Murli-Khaire-Resume.pdf`
